# Starting evidence and source boundary

Prepared 19 September 2026. These are selected starting sources, not a requirement
to reproduce every earlier study. Continue discovery as the chosen workload and
uncertainty sharpen. No public benchmark or upstream code has been adopted here.

## Closest public methods

| Exact version | Relevance and reading boundary |
|---|---|
| [Grounding Agent Memory, 2609.11060v1](https://arxiv.org/html/2609.11060v1) (root P48) | Root inspected methods, prompts, setup and cost accounting. Environment-probing curation is direct prior art. Task-cost comparisons exclude curation; examine full-cost value and shared-candidate acceptance rather than claiming a new verification loop. |
| [CHIME, 2609.02074v1](https://arxiv.org/html/2609.02074v1) (P92) | Root inspected §§3–6. Reflective selection is a serious comparator; agreement and same-episode rescue are not proof of later lesson value. |
| [Causal Agent Replay, 2606.08275v1](https://arxiv.org/html/2606.08275v1) (P93) | Root inspected §§2–5, 7. A possible executed-check method; its synthetic validation does not establish reusable lesson scope or cost repayment. |
| [RSIAgent, 2609.15364v1](https://arxiv.org/html/2609.15364v1) (P94) | Root inspected §4.6, §7, §§8.1–8.3. Separates artifact verification from actor-owned memory writing; narrow the claim to acceptance evidence and later use. |
| [Memory-R1, 2508.19828v5](https://arxiv.org/html/2508.19828v5) (P40) | Prior root reading covers separate learned memory management and use. Consult if learning a decision policy becomes consequential; no RL reproduction is commissioned. |

accepts `09f66837ca76db1f674ee3372d734219ad0f3e27`. Its learned read/deliver worker
completes 26/28 original final tasks versus frozen memory's 9/28 and ordinary
retrieval's 28/28. Authority and teaching remain supplied. Record-ID/order changes
break the learned selector. Root independently regraded 176 saved tasks, but ran
no fresh inference. Its source catalog is an engineering example, not a workload
for measuring uncertain lesson acceptance.
