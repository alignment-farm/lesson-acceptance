# Pilot v1 — frozen before collection

2026-09-19. Investigator-authored, motivated constructed SQLite reporting episodes;
not a public benchmark or naturally sampled failure distribution. Two independent
source histories: invoice totals with payments, and event attendance with tags.
Both expose full schema, explicit primary/foreign keys, all rows, and requirements.
The source slice has at most one detail and one auxiliary row per entity; no
uniqueness constraint promises that future slices do. Ordinary complete solutions
are permitted. A model writes source SQL, sees its execution (not a hidden answer),
and proposes reusable lessons. The investigator grades source outcomes separately.

Freeze original proposals. Raw reuse keeps source observations and SQL. Cheap
acceptance additionally receives model reflection on source, requirements and
schema. Paid acceptance receives those same inputs plus a fixed, investigator-
authored multiplicity challenge with ordinary SQLite execution of acquired SQL.
It is a check-all policy, not selective probing. Paid checks use constructed
development data, never final rows or answers. Rewriting must be explicit.
Every later arm receives all source material and acquired code, plus its own
acceptance record; paid evidence is retained and charged.

First run two source competence checks and four acceptance calls. Continue to a
small fresh comparison only if source acquisition works. Freeze harness and
policies before generating final rows. Final cases vary multiplicity, empty groups,
duplicate display labels and retained filtering obligations. Full task rows and
requirements are visible; independent expected answers are never sent to model.
SQL execution output is ordinary feedback; each task gets one optional revision
after executing its first answer. Evaluator examines complete rows and SQL's
behavior on the fixed fresh cases; no claim of formal operational equivalence.

Local ceiling: 60 model calls, 45 minutes, serial inference, 8B model first,
temperature 0, at most 4096 completion tokens/call. No weight downloads/training.
Remote endpoint availability was checked; no local Docker models were running.
Remote machine-wide occupancy is unknown; serial low-volume requests only.
Escalation to 27B would require demonstrated model competence failure within this
same budget, with separate records. No paid API spending is planned.

Log full prompts/responses, tokens when returned, wall seconds, source/proposal/
acceptance/probe/later work separately. Engineering and delegated investigator
tokens/money are unknown, not zero. Report paired full-task outcomes and a measured
reuse horizon, not acceptance accuracy alone. This pilot cannot estimate natural
bad-lesson prevalence or broad transfer. Preserve failed attempts.

The prepared owned runtime is missing. A small stdlib SQLite/HTTP instrument is
used instead; the derivative and sibling studies remain untouched.
